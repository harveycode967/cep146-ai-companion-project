# AI Evaluation

This folder holds the full record of asking two different AI models to grade the finished project.

ai-model-1.md holds the full prompt and full response from the first AI model. ai-model-2.md holds the full prompt and full response from the second AI model. Save both the exact prompt used and the AI's complete reply, not just a summary; the instructor needs to see exactly what was asked. The prompt should include the GitHub repository link, the YouTube video link, and the grading rubric from the project guidelines.
